# Melow website

The public pages for Melow, the music player for iPhone, iPad and Mac:
the home page, [support](support/), the [privacy policy](privacy/) and the [terms of use](terms/).

Served by GitHub Pages at <https://rchen14b.github.io/melow-site/>. Plain HTML, one stylesheet and
a small script for the nav bar, with no build step. These addresses are linked from Melow's Settings
and its purchase screen, and given in App Store Connect, so keep the paths stable.
